# 🚀 CRUD REST API

A RESTful API built using Node.js and Express that performs basic CRUD (Create, Read, Update, Delete) operations.

---

## 📌 Features

- Create new resource
- Read all resources
- Read single resource
- Update existing resource
- Delete resource
- RESTful routing
- JSON request & response handling

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB / File System 
- EJS / Postman (if used)

## 📬 API Endpoints

### 🔹 Create

```
POST /create
```

### 🔹 Read All

```
GET /
```

### 🔹 Read Single

```
GET /files/:filename
```

### 🔹 Update

```
PUT /update/:id
```

### 🔹 Delete

```
DELETE /delete/:id
```
